响应式中文职业指南。场景：2026 年 9 月入读 Bristol LLM，2027 年 5 月起可回国全职实习。

**公开网站：** https://zhouyi-xiaoxiao.github.io/bristol-law-career-roadmap/

## 内容边界

5 月全职到岗是已确认的规划条件。背景是假设组合，不代表真实个人身份。招聘与活动只在有官方依据时写确定日期，不用往年日期推测 2027 截止。AI 发布核查不是模型性能评测，企业功能不等于学生账号已开通。页面不调用 AI API，也不提供法律意见、上传合同或自动投递。

源文件 `src/content.json` 保存职业指导；`src/frontier.json` 保存前沿更新。每条来源有自己的核查日期，界面更新时间不意味着所有来源已再次核查。静态站没有分析追踪、第三方脚本或后端；全部正文在 HTML 内，无 JavaScript 时仍可阅读，并显示交互不可用提示。

## 构建与检查

```sh
python3 scripts/build.py
python3 scripts/check.py
node --check docs/assets/app.js
python3 -m http.server 8765 --directory docs
```

`docs/` 由 GitHub Pages 的 `main /docs` 发布。本轮实际浏览器回归覆盖 320、390、768、1024、1440 像素的 12 章节，以及搜索、过滤、复制和本地进度刷新。原有独立 Playwright 回归脚本同步适配新章节，运行需安装 Playwright 和 Chrome；本轮交互核验通过 CUA Chrome 完成。

## 更新与恢复

修改内容、重新构建、验证后提交到 main。使用 `git revert` 创建恢复提交，不重写公共历史。每次发布前在本地保留原始快照、补丁、验证输出和恢复脚本；它们不发布到公开站点。
